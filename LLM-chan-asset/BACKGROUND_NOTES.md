# 七角色背景重制：设计与来源

研究日期：2026-11-09。此文记录七套背景的设计依据、制作契约与证据边界；人物已经定稿的表情、发型、服装、配饰和原生坐标不在本轮修改范围内。

## 人设采用顺序

用户定稿优先：DeepSeek 是“爱吃白饭的大肥鱼”；Claude 是家教很严、神态舒缓的温婉大小姐，嘴角收平；GLM 是犯困的贪睡虫，保留半睁眼、自然闭口，不恢复哈欠。其余角色沿用当前 ZipZipPipe 正常比例立绘的视觉身份。

联网材料分三类使用：原作者发布和人设图提供视觉母题；二创作者的角色卡只支持该作者版本；厂商文章只提供命名或产品创作语境。七个具体房间、庭院和露台均为本项目原创环境扩写，不宣称是原作者设定的故乡、住所或固定剧情场景。

## 联网证据边界

- ZipZipPipe 的角色总帖本轮可以读取；GPT 三视图、Grok 壁纸、千问配色三视图等部分单帖，以及 Pixiv 图集原页未能正常读取。所选正常比例原图仍以本地来源记录为准，不把访问失败的页面写成已核实文本。
- ApprenTice 提示词是该派生作者对自己作品的一手制作说明，不是 ZipZipPipe 的原始世界观。背景只吸收视觉方向，不复制提示词全文，也不移用其人物比例或新道具要求。
- Neko3000 的人物表与性格说明均是独立漫画二创。Claude 的教养与 DeepSeek 的吃饭反差可作补充，用户本轮指定的人设优先于其可选演出规则。
- GLM 社区角色卡与逆向立绘说明不是厂商官方设定，也不作为原画授权证明。本项目仅采用与当前视觉及用户定稿相符的书卷、眼罩和休息母题，不转述其中无关争议断言。
- 白饭梗视频 [BV184HC6FEfr](https://www.bilibili.com/video/BV184HC6FEfr/)的搜索简介可见，原页读取返回 412；不据此断言完整剧情、对白或梗的唯一出处。
- Gemini 与 Grok 的厂商文章支持命名／创作语境，不证明猫娘、吸血鬼或具体场景是品牌官方角色设定。

## 制作与接入

七张场景采用 OpenAI 内置 `image_gen` 新绘，原稿按 `source-art/backgrounds/{id}-source.png` 保存；提示词与内置模式记录保存于 `source-art/backgrounds/generation-prompts.json`。旧 QQ 秀背景只作像素密度、构图和色彩方向参考，不复制其像素到新背景。新背景不包含人物，不把既有穿戴部件烘焙进去。

`tools/classic-backgrounds.mjs` 负责角色主题与原稿读取。适配先按 `cover`、中心裁取、最近邻缩放到 **140×226**，再输出 256 色、`dither: 0.1` 的 PNG，并经 `toPixelSvg` 转为不嵌入位图的纯路径 SVG；前端继续加载 `public/assets-classic/{id}/background.png`，SVG 导出读取同目录 `background.svg`。只替换 `background` 槽的资源和名称，层级仍在人物之后。

中心和头部周围控制对比与细节，把场景识别物放在侧边、上方或地面；不得以缩小或挪动人物来解决遮挡。所有背景为静态图，没有新增 GIF 动画。

构建脚本将每张原稿尺寸、SHA-256、适配参数、制作模式和风格参考路径写入 `public/assets-classic/source-references.json` 与 `previews/classic/build-report.json`。生成图片、派生 SVG、原稿和参考图仍沿用仓库现有忽略规则保留在本地；联网文本链接不会额外授予第三方角色或旧素材权利。
