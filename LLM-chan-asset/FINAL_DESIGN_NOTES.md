研究与整理日期：2026-11-09。

本轮继续采用项目已选定的 ZipZipPipe 七家正常比例参考形象，把服装、配饰和轮廓转译为原版经典 QQ 秀的表现方式。原始 `default` 和 `qq-show-classic` 的人物比例、细线描边、小画幅着装层次优先；不改成二创图集的大头短身 Q 版。模型产品版本更新不等于拟人角色换装，未核实的新图不用于强制替换当前身份。

共同方向是让人物先有完整着装轮廓，再用少量易辨认的小饰件补足身份。人物采用经典 QQ 秀的细线描边、克制高光和服装分层；不靠增加光环、巨型标志或持续飘动的碎屑表达品牌。人物瞳色与此前用户确认的神态继续保留。

## 排除误标的 ComfyUI 图片

本轮实际目视本地 `ai-girls-atlas/assets/zipzippipe/claude/zipzippipe-pixiv-150718881-p04-variant.jpg`：安全帽、胸口与工具袋可见文字为 **ComfyUI**，并非 CLAUDE。虽然本地台账和文件路径曾将它归入 Claude 工程服变体，图片本身不能支持这一归属。

因此，本项目不将该图作为“Claude 最近变成黑紫龙娘工程服”的证据，也不据此替换用户选定的橙发礼服大小姐。原始资料文件及台账不在本说明的修改范围内，保留原样供后续独立整理。

## 导出与验证

每个角色已生成以下独立文件，成品放在已忽略的 `deliverables/classic-final` 目录中：

- 140 × 226 的完整场景 PNG。
- 同画幅、透明背景的人物 PNG，保留完整人物与随身配饰。
- 循环 GIF：人物姿态、面部、衣装和背景构图固定，只让少量既有特效轻微闪烁。
- 420 × 678 最近邻放大场景预览。

`npm run assets:classic`、`npm run assets:export` 已完成。七个 GIF 均经实际解码确认为 140×226、8 帧、每帧 240ms、1.92 秒无限循环，具有不同画面帧；特效区域之外变化像素为 0。原生尺寸、整数倍合成图与解码帧已查看，文件哈希和解码参数记录于 `export-report.json`。已定稿脸部、新背景及原 default 目录与本轮装扮修改前哈希一致，default 与原五层合成逐像素差异为 0。

修改脚本静态语法、生产构建与前端/工具依赖审计通过（均 0 vulnerabilities）。未新增测试代码，未执行完整 UI 回归或穷举混搭。图片、GIF、原稿及参考库继续保留本地；公开范围依照根目录 `COMPLIANCE.md`，此次导出不新增美术再分发授权。
