## 一轮的状态

`draft → author-reviewed → applied/frozen → evidence-captured → independently-reviewed → revision-required / accepted`。

没有本版本实际图像和匹配哈希，不能从“命令已启动”“工具握手”“打开请求已排队”或“静态量测通过”跳到accepted。改变任一部件使相应评分待复审；改变成品使全套评分待复审；换seed/池/上下文使随机融合评分待本轮评审。

多件AI混搭须重新实际评审，不能拿已合格的单件分数相加/平均推导。变更集合也改变上下文签名；完整partHashes有一个变化就重新审该组。素体必须和default及20个不同着装/姿态原生样例一起评，不能只保留default好看的视角。

未变范围可按 [精确范围携带规则](REVIEW_WORKFLOW.md#6-修改后复评与未变范围携带)保留原分、原 seed、原图和来源；必须明确它是原范围证据。body 未变而只改头发时，可携带匹配的 body/衣装组记录，包括既有失败；旧 full 不能证明新头发下的完整形象。换 hash 不自动清历史形体问题。

## 修改优先级

1. 肢体和手掌的自然饱满肉面、比例与连接；定位细杆、掌跟薄、重复肢体、断边、尖刺、断接及真实持物承压缺陷。
2. 发型/刘海、衣型与服装材料，同时核对 normal 还原和原生融合；颜色只核对应色相，姿态仅非常显著差异扣还原，中等及以下扣0。
3. 原生 Classic 像素、Y2K、Blingee Pixel 的清楚轮廓、主暗谷、窄亮峰、小尺度色簇与前后层级；华丽细节不能糊合成一片。
4. 最后补小纹样/闪点，不能先堆装饰掩盖前三级问题。

素体与服饰共用关节；改变体块后跟随修改衣服，不用长裙遮住不合格素体。default皮肤可直接转SVG保留原像素，重摆pose时不能缩细腿腾空间。皮肤crisp规则不能一并套到所有材质；“颜色相同”不等于“笔触相同”。

default 两处截面宽只描述源点，不是全部姿态的目标宽。用户5%是20例原生对照中明显可感知差异的要求；量测须先建立同解剖对应、可见成分、投影及控制，再结合持续真差和原生同尺度可见缺陷判断。不得为单点过线削肉，旧不利数值与方法不确定性继续保留。真实原生紧凑指群、合理角阶与负形不强改为写实五指；接触先辨明书/碗/柄与悬浮物、立式麦克风、装饰的语义。
