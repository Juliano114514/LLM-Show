## 推荐审阅顺序

1. **确认输入和证据是否存在**：角色、标准JPG/MD版本、原生池、模型、规则版本、input/native/model哈希、轮次和seed。不能假设归档仍在。
2. **先全面首扫**：21槽至少各看一例；同时看完整裸标准体和直接6x，逐项检查双侧肩、肘、腕掌及腰髋膝踝，避免每轮只发现另一侧旧问题。
3. **复核低点**：失败或疑似部件进入五种有效原生语境，结合孤立件、完整原源、相邻接合及多AI组合确认归属。短裙单尾、原生短发角根、袖腕和手物接触不能省略。
4. **检查还原**：实际并排看完整JPG、MD、全套及标准裸姿态；动作和色相分别记录，遮挡处保留未知。
5. **决定覆盖深度**：已确认失败可先出精确部分报告；只有要宣称整套接受时，才必须补齐246及标准7/20/6x。截图数、循环次数、生成数不等于已审数。
6. **明确结果状态**：未审、原生上下文无效、确认失败、部分通过、完整接受分别写明；局部98不能显示成整套98已通过。
