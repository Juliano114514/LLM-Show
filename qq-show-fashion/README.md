# Fashion 原生素材

- `fashion/raw/`：原生 SWF。
- `fashion/extracted/`：原件的帧与 Shape SVG 导出。
- `fashion/previews/`、`fashion/thumbnails/`：原生首帧和商城缩略图。
- `catalogue.json`、`manifest.json`、`fashion/*manifest.json`：素材清单与来源。

原生浏览页在 `../workplace/frontend/fashion/native/index.html`。恢复脚本在 `../workplace/LLM-show-fashion/tools/native/`；恢复研究和工具链在该项目的 `ai-workspace/native-recovery/`。AI 绘制素材不放入此处。
