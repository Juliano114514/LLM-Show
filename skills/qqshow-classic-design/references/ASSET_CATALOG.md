# 素材目录与真实兼容边界

素材根目录记为 `assetRoot`，本工作区是 `qq-show-classic/`。下文所有素材路径都相对此目录。统计日期：2026-11-09；移动本包后用实际目录替换，不依赖该盘符。

## 规模与编码

- 1,296 个源文件：1,291 张图像、5 个字体文件。
- 1,289 张图像用于换装或场景；另有图标、界面截图各 1 张。
- 621 张多帧图像；文件头识别为 GIF 的有 1,270 张，PNG 有 21 张，不能只看扩展名。
- 1,286 张图像为 `140×226`。其余是 3 张异常尺寸图层，以及图标和截图。
- 21 张 `default`：16 张全透明空图，5 张是默认人物部件。
- 声明图像帧总数 3,820，严格解码成功 3,819 帧；1 张 GIF 的最后一帧报截断错误，见下方异常表。

机器索引 [asset-index.json](asset-index.json) 包含每个图像的相对路径、真实编码、尺寸、声明/已解码帧数、解码错误、逐帧时长、循环、disposal、alpha 边界与 SHA-256。所有范围的右/下边界均不包含在内。`decoded_frames_alpha_bbox` 只覆盖成功解码的帧；`empty_all_frames: null` 表示无法完整判断。索引是快照，目录变更后重新检查。

## 发型配对

- 排除默认图后，有 28 个文件名能在前发、后发两侧找到同名候选。这是文件名对应，不是对动画节奏、颜色或穿戴的全面保证。
- `back-hair/白金卷短发.gif` 没有同名的前发文件；不根据名字自动补一张或强配其他白金头发。
- `front-hair/棕色发夹侧扎卷发.gif` 与 `back-hair/棕色发夹侧扎卷发.gif`、`front-hair/白金双马尾.gif` 与 `back-hair/白金双马尾.gif` 可作为已做静态组合的参考对。
- 没有匹配后发的前发，可先检查其本身是否已覆盖完整可见轮廓。用户只换前发时，不应无条件回填默认棕色后发。

## 快速查询索引

例如在本 skill 目录运行 PowerShell；只读取本地文件：

```powershell
$qqIndex = Get-Content -LiteralPath './references/asset-index.json' -Raw -Encoding utf8 | ConvertFrom-Json
$qqIndex.images | Where-Object { $_.category -eq 'front-hair' -and $_.path -like '*棕*' } | Select-Object path,size,frames
$qqIndex.images | Where-Object { $null -ne $_.decode_error } | Select-Object path,decode_error
```

对已变更目录重新读取实际文件，索引中的历史 SHA-256 可用于发现变化；不要把旧统计当成当前状态。
