# 生成配方与可直接改写的提示词

先读 [主规则](../QQSHOW_DESIGN_RULE.md)。下文的主题名、配方与字段是本包建议；路径来自本地素材。提示词本身不代表已经生成、校准或验证了资产。

## 1. 最小创作 brief

```text
对象：完整搭配 / 新部件 / 场景闪图 / 配套 UI
主题与情绪：例如“樱花放学后，轻松、带一点甜酷”
素材根目录：实际 assetRoot
具体参考：3–5 个真实素材路径，说明各自借鉴点
输出：原生大小、透明/带背景、静态/动画、预览要求
可替换部件：类别、姿态族、包含的身体区域、冲突槽位
文字：需要准确出现的短句；没有就不强加
```

用户没给齐时，通常可选当前默认底板和最接近的风格分支继续；只有缺失参考或姿态冲突会决定成败时才澄清。没有资源访问能力时交付设计稿描述，并明确未查看原图。

## 2. 通用视觉提示词

中文模板：

```text
为【具体对象】创作【主题】的经典二维 QQ 秀内容。
参考提供的本地素材，保留它们的细密像素密度、轮廓节奏与人物尺度。
视觉语言为千禧年代亚洲网络纸娃娃换装：大眼、小鼻口、纤细四肢，
清晰发束、服装褶皱与小面积高光；按【甜酷日常/街头摇滚/梦幻礼服/黑白情绪】搭配。
主色【颜色】，辅色【颜色】，强调【材质或标志元素】。
构图【部件原坐标 / 人物居中、边缘装饰】，明确保留【脸/领口/腰线】。
输出【140×226 对齐目标 / 指定画布】、【真实透明背景 / 场景背景】、【静态/多帧要求】。
只生成【对象范围】，不额外补充未要求的头发、脸、身体、文字或背景。
```

英文辅助短语可用于支持英文提示的工具：

```text
Classic 2D QQ Show paper-doll dress-up aesthetic, early-2000s East Asian web fashion,
fine low-resolution raster detail, crisp stepped contours, expressive large eyes,
slender stylized proportions, clustered hair highlights, readable tiny garment folds,
purikura-like ornament and selective blingee sparkle, aligned to the supplied base.
```

只保留与当前对象有关的短语。生成耳环时不要求整个身体，生成 UI 时不要求每个按钮都画大眼睛。

## 3. 风格纠偏词

用于约束生成，不是对所有时代 QQ 产品的价值判断：

```text
避免：三维塑料公仔、写实皮肤、摄影布料、电影景深、柔焦空气刷、
通用二次元大海报、两头身婴儿比例、粗大 8-bit 方格、满屏赛博霓虹、
光滑矢量扁平插画、现代毛玻璃仪表盘、自动增加文字和水印。
```

若用户明确要求某种延展，可改变对应方向，同时保留可识别的轮廓与换装约束；不要让负向提示覆盖用户目标。

## 4. 配方 A：直接用旧素材搭完整 QQ 秀

已经做过静态首帧搭配示意的四组配方：

| 主题 | 从后到前的素材路径 | 已覆盖的观察 |
| --- | --- | --- |
| 樱花放学后 | `backgrounds/樱花别墅.gif` → `back-hair/棕色发夹侧扎卷发.gif` → `outfit/可爱粉色外套套装.gif` → `makeup/default.png` → `front-hair/棕色发夹侧扎卷发.gif` | 同名双层发型与整套服装 |
| 午夜街头 | `backgrounds/夜半城市.gif` → `outfit/潮流迷彩牛仔短裤套装.gif` → `head-set/墨镜红棕飞机头.gif` | 整头与套装的简短组合 |
| 花园礼服 | `backgrounds/梦幻仙岛.gif` → `wings/白色天使.gif` → `back-hair/白金双马尾.gif` → `outfit/粉色公主礼服套装.gif` → `makeup/蓝眼wink.gif` → `front-hair/白金双马尾.gif` | 后置翅膀、礼服、双层发型 |
| 黑白心情 | `backgrounds/黑白云朵.gif` → `outfit/黑色西装套装.gif` → `head-set/墨镜栗子头.gif` → `frame/黑色星星.gif` | 坐姿套装、整头与边框 |

对应 [示意图](visual/recipe-board.png) 与 [结构化清单](example-recipes.json)。这些是完整显式图层数组，不额外回填默认衣服和头发；也不代表全套动画已经同步验证。

可直接发给执行者：

```text
使用 qqshow-classic-design，以“樱花放学后”配方为起点做一套经典 QQ 秀。
先沿用真实素材；只在原生画布完成组合，不裁边、不逐件居中。
再挑一件不挡脸的小配饰，先检查套装是否已有同类物件。
交付实际素材路径、最终 140×226 静态合成和 3 倍预览。
若用动画素材，仅交静态时说明取帧，不宣称完成动画导出。
```

## 5. 配方 B：新增可换装的上装

```text
目标：粉白蝴蝶结短外套，经典二维 QQ 秀 top 部件。
参考 top/default.gif 的上身、手臂与手势，bottom/default.gif 的腰胯连接，
makeup/default.png 的肤色；另查看 top/粉色短外套.gif 的材质和轮廓。
仅绘制上身、手臂、手、外套和内搭；脸、头发、下装与背景不画。
最终目标画布 140×226，透明背景，保留默认站姿的全部原始坐标。
主色淡粉，白色内搭与蝴蝶结；少量深粉折痕和白色小亮点。
不使用摄影布料或大面积柔焦渐变，原生尺寸仍能看清袖口与衣摆。
交付部件透明图、与默认下装及脸发的合成预览，说明兼容范围。
```

若工具只输出较大的候选图，先保留相同画布比例和参考位置，之后再做像素整理与对齐。缩小结果必须实看；未整理前不得标为 `ready-to-wear`。新增上装不能把默认手臂残留在下面，也不能生成第二套手指。

## 6. 配方 C：成对头发

```text
目标：金棕蝴蝶结侧马尾，适配 makeup/default.png 的脸与默认站姿。
查看 front-hair/棕色发夹侧扎卷发.gif 与 back-hair/棕色发夹侧扎卷发.gif，
借鉴前后遮挡与像素密度，不改脸的位置。
以一套轮廓设计分别输出前发和后发，两张均为 140×226 透明画布。
后发在脸和身体后方；前发只覆盖应有的刘海与侧边发束。
不把脸、耳朵、衣服或背景烘焙进头发。
交付两张图、叠脸预览，以及头饰是否内置的说明。
```

图像工具不能可靠分层时，先生成有明确遮挡说明的设计稿，再拆层整理。生成一张漂亮的完整人物图，不等于已经交付两张可替换头发。

## 7. 配方 D：心情闪图与边框

```text
目标：“等你上线”星夜边框，配套经典 QQ 秀人物。
参考 frame/黑色星星.gif 的边缘分布、sparkle/蓝色流星.gif 的局部亮点，
text/等你电话哦.gif 的心情装饰语气，保留当前人物头部与身体占位。
主画布 140×226，边框为独立透明层；装饰集中在四周，中央脸部清楚。
蓝紫主色，少量冰蓝星点与白色高光，不加整个场景的镜头缩放。
文字准确写“等你上线”，作为后期排字层；先保证汉字结构，再添加小亮点。
如果制作动画，让星点依次点亮并复位；人物和文字位置保持稳定。
交付静态层及预览；多帧输出另列实际帧数、各帧时长与循环检查结果。
```

默认建议将文字与闪效拆开，避免每次改句子都重绘边框。只有用户要“一张带字成品”时再合并输出，不要求所有场景都强制拆文件。

## 8. 配方 E：配套物品卡与换装面板

```text
目标：经典 QQ 秀换装面板中的“套装”物品卡与分类按钮。
界面参考 qq-show-classic/screenshots/opengraph.png，它是复刻站参考。
使用浅灰工作区、蓝紫渐变容器、白色物品卡、薄描边与轻凸起按钮。
物品卡包含等比素材预览、短名称、清楚的选中边线与勾选标记。
分别给出默认、悬停/焦点、选中与不可用状态；正文保持清楚可读。
人物图层仍按原生坐标处理；卡片布局不能反过来改写素材画布。
小饰品可加局部缩略图，但另保留完整穿戴源文件。
不要把主视图改成毛玻璃、超大胶囊按钮和大幅写实宣传图。
交付组件说明或用户指定框架的实现；不虚构收费、会员开通或购买服务。
```

只要求设计时交设计，不自动建站、安装依赖或发布。需要代码时按所在项目现行组件、样式与资源路径实现。

## 9. 完成度用语

| 实际状态 | 可用表述 |
| --- | --- |
| 只有说明与提示词 | “设计 brief / 生成提示词已完成，图像待生成” |
| 有静态大尺寸候选 | “候选稿已生成，像素整理与锚点待校准” |
| 有原尺寸透明图与已查看的合成 | “静态部件已输出，已检查列出的搭配” |
| 有实际多帧文件及播放检查 | “动画已输出，已检查指定环境下的帧时序与循环” |

只报告实际交付，不把“想要生成”写成“已经生成”，也不把某一搭配通过写成全库兼容。
